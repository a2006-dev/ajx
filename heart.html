CH-01
📶蓝牙 BLE 连接
支持标准心率服务 0x180D，兼容 Polar、小米手环等。断开自动重连，只连已知设备。
CH-02
📈ECG 仿真波形
P-QRS-T 生理模型仿真，每跳形态各异，基于 RR 间期动态调整，未连接时显示待机基线。
CH-03
📊HRV 实时监测
SDNN 实时计算：有 RR 数据时为真实值，无 RR 时基于心率估算。30 秒滑动平均稳定显示。
CH-04

5 种样式，自定义颜色/字号/透明度，位置自动记忆；游戏模式自动切换超小悬浮窗。

# OBS overlay OBS 来源 → 浏览器 URL: http://localhost:9091?transparent=1
CONNECT

三种推荐连接方式，按需选择：

# WiFi 局域网 手机开启心率广播 → PC: heart_client.exe 192.168.1.5:9090 → 浏览器 localhost:9091 # USB 直连 手机插线开 USB 调试 → PC: heart_client.exe -usb (需 adb.exe 同目录) # MQTT 远程 手机: 设置 → MQTT 远程 → 复制连接码 → PC 粘贴即连

MQTT 连接码格式（实际话题自动追加设备标识 heart/rate/GUEMSNDM）：

HEARTBEAT#V1#GUEMSNDM#broker-cn.emqx.io:1883#heart/rate
段说明
HEARTBEAT#V1#固定头 + 协议版本
GUEMSNDM8 位随机设备标识，区分用户
broker-cn.emqx.io:1883MQTT 服务器地址 + 端口
heart/rate话题前缀，实际订阅自动追加设备标识
