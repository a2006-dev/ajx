▚▚ LOG CATCHER ▞▞

Android 日志捕获应用 · Console 极简控制台风格 · 基于 Shizuku 实时抓取指定应用日志

API : 28+  ·  Kotlin : 1.9.20  ·  License : MIT  ·  Shizuku : 13.1.5
CORE FEATURES // 核心功能
应用选择器
列出所有已安装应用，支持搜索与系统应用切换，快速定位目标进程。
实时日志捕获
通过 Shizuku 执行 logcat，按 PID 过滤指定应用的全部日志输出，终端式实时刷新。
崩溃检测
自动检测进程退出时的 FATAL EXCEPTION，双通道捕获崩溃堆栈，不放过任何异常。
日志保存 / 分享
一键保存为 .txt 至 Download/LogCatcher/，通过 FileProvider 直接分享。
两种捕获模式
普通模式输出全部日志；错误模式仅保留 E/W/F 级别 + 异常关键词，脏数据零干扰。
双层主题
Material 3 亮 / 暗双主题，27 个语义化色彩 token，终端式简洁界面。
REQUIREMENTS // 前置条件
Android 版本Android 9.0 (API 28) 或更高
Shizuku必须安装并授权 Shizuku v13+ — shizuku.rikka.app
存储权限Android 9 以下需手动授权存储权限（targetSdk 已声明 maxSdk=28）
USAGE // 捕获流程 · 4 步
01
授权 Shizuku
首次启动点击「去授权」，通过 Shizuku 授权后获得特权进程能力。
02
选择应用
顶部「选择应用」，从列表中选择目标应用（可搜索、可切系统应用）。
03
启动捕获
点击 ▶ 自动拉起目标 App，按 PID 持续过滤 logcat 输出。
04
保存 / 分享
底部操作栏保存 .txt 或直接分享；进程退出自动做崩溃检查。
