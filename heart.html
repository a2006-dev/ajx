❤️ 心迹 Heart

蓝牙心率监测 · 跨平台广播 · OBS 直播叠加 · MQTT 远程推送

v3.1 MIT License Java + AndroidX Go / Python

🔥 它能做什么

心迹是一款开源的蓝牙心率监测工具，通过 BLE 连接心率设备，将实时心率展示在手机上，并通过 WiFi / USB / MQTT 多种方式推送到电脑。核心亮点就是把心率带到任何屏幕。

📶
蓝牙 BLE 连接
支持标准心率服务 0x180D，兼容 Polar、小米手环等。
📈
ECG 仿真波形
P-QRS-T 生理模型仿真，每跳形态各异，基于 RR 间期动态调整。
📊
HRV 实时监测
SDNN 实时计算，有 RR 数据时为真实值，无 RR 时基于心率估算。
🪟
悬浮窗
5 种样式，支持自定义颜色/字号/透明度，位置自动记忆。
📡
MQTT 推送
跨互联网推送心率，支持公共 Broker / Docker 自建 / 云平台。
🔗
连接码机制
一键生成 HEARTBEAT#V1# 格式连接码，电脑端粘贴即连。

🖥️ PC 三端客户端

同一个心迹项目，在电脑上提供了三种接收方式，覆盖不同的使用场景：

版本特点适用场景
Go 版单文件 ~5.6MB，免安装运行时，OBS 叠加?transparent=1，支持-usb直连Windows 快速部署、直播叠加
Python 版tkinter 图形界面，7 种悬浮窗，HRV 实时折线图，局域网扫码功能全量、可二次开发
网页版纯浏览器 MQTT 接收，零依赖，可部署 GitHub Pages零安装、临时查看

💬 手机和电脑怎么连

三种推荐连接方式，按需选择：

# WiFi 局域网 · 手机开心率广播 → PC 运行 heart_client.exe 192.168.1.5:9090 → 浏览器 http://localhost:9091 # USB 直连 · 手机插线开 USB 调试 → PC 运行 heart_client.exe -usb（需 adb.exe 同目录） # OBS 叠加 · OBS 来源 → 浏览器 → URL: http://localhost:9091?transparent=1

MQTT 远程推送，突破局域网限制，随时随地查看心率。连接码格式如下：

HEARTBEAT#V1#GUEMSNDM#broker-cn.emqx.io:1883#heart/rate
段说明
HEARTBEAT#V1#固定头 + 协议版本
GUEMSNDM8 位随机设备标识
broker-cn.emqx.io:1883MQTT 服务器地址 + 端口
heart/rate话题名称，实际订阅自动追加设备标识

实际接收的话题 = heart/rate/GUEMSNDM
